# Лабораторная работа №2 — Разбор и вычисление выражения

## Задание

Разобрать математическое выражение и вычислить его значение.

Выражение может содержать:

* числа;
* знаки операций;
* скобки.

Если выражение записано корректно, программа должна вычислить значение.  
Если выражение некорректно, программа должна вывести сообщение об ошибке.

Дополнительно приветствуется поддержка имён переменных и различных функций.  
Если в выражении есть переменные, их значения нужно запросить у пользователя.  
Для каждой переменной значение запрашивается один раз.

## Реализованный функционал

Программа поддерживает:

* целые числа;
* дробные числа;
* пробелы внутри выражения;
* операции `+`, `-`, `*`, `/`, `^`;
* правильный приоритет операций;
* скобки;
* вложенные скобки;
* унарный плюс;
* унарный минус;
* переменные;
* запрос значений переменных у пользователя;
* сохранение значения переменной после первого ввода;
* математические функции;
* математические константы;
* обработку ошибок.

## Поддерживаемые функции

Поддерживаются функции с одним аргументом:

* `sin(x)` — синус;
* `cos(x)` — косинус;
* `tan(x)` — тангенс;
* `sqrt(x)` — квадратный корень;
* `abs(x)` — модуль числа;
* `ln(x)` — натуральный логарифм;
* `log(x)` — десятичный логарифм.

## Поддерживаемые константы

* `pi` — число π;
* `e` — число Эйлера.

## Принцип работы

Для разбора выражения используется рекурсивный спуск.

Выражение разбирается по уровням приоритета:

* expression — сложение и вычитание;
* term — умножение и деление;
* unary — унарный плюс и унарный минус;
* power — возведение в степень;
* primary — числа, переменные, функции и выражения в скобках.

Грамматика выражения:

expression = term { ("+" | "-") term }

term = unary { ("*" | "/") unary }

unary = ("+" | "-") unary
      | power

power = primary [ "^" unary ]

primary = number
        | variable
        | constant
        | function "(" expression ")"
        | "(" expression ")"

## Переменные

Если выражение содержит переменную, программа запрашивает её значение у пользователя.

Например:

a + a * 2

Программа спросит значение переменной a только один раз.
После этого сохранённое значение будет использовано во всех местах выражения.

Для хранения переменных используется собственный класс VariableStorage.

Хранилище реализовано на основе двух массивов:

* String[] names
* double[] values

Встроенные коллекции Java для хранения переменных не используются.

## Обработка ошибок

Программа обрабатывает следующие ошибки:

* пустое выражение;
* неожиданный символ;
* некорректное число;
* отсутствие правого операнда;
* лишняя закрывающая скобка;
* отсутствие закрывающей скобки;
* деление на ноль;
* неизвестная функция;
* квадратный корень из отрицательного числа;
* логарифм от неположительного числа;
* отсутствие значения переменной.

## Основные классы
* Main.java - консольный интерфейс программы.

* ExpressionEvaluator.java - внешний класс для вычисления выражений.

* ExpressionParser.java - Основной парсер выражения. Реализует рекурсивный спуск.

* ExpressionException.java - Исключение для ошибок разбора и вычисления выражения.

* VariableStorage.java - Хранилище значений переменных.

* VariableProvider.java - Интерфейс для запроса значения переменной.
